# Drawing in Gleam

Load this only when the user says they use Gleam or asks about it. Checked against the official documentation on 8 September 2026. Re-verify before quoting plan limits, and state nothing beyond the linked pages.

- **Campaign draws.** From a competition's Winners tab, choose how many winners to draw, optionally restrict entries by date, and draw. With several prizes, drawing "All Prizes" assigns winners in prize-list order, or draw per prize. The docs say Gleam uses Random.org for random draws and does not contact winners automatically ([Drawing Random Winners](https://gleam.io/docs/competitions/post-campaign/random-winners)).
- **Manual winners** exist for skill-based competitions, and the docs say manual draws are audited ([Selecting Manual Winners](https://gleam.io/docs/competitions/post-campaign/manual-winners)).
- **Quick Draws** are standalone tools for lists that did not come from a Gleam campaign: [Overview](https://gleam.io/docs/competitions/quick-draws/overview), [Random Name Picker](https://gleam.io/docs/competitions/quick-draws/random-name-picker), [Instagram Comment Picker](https://gleam.io/docs/competitions/quick-draws/instagram-comment-picker), [Competitions Live Draw](https://gleam.io/docs/competitions/quick-draws/competitions-live-draw), [Multiple Campaign Draw](https://gleam.io/docs/competitions/quick-draws/multiple-campaign-draw). From the overview page (updated 8 September 2025): a Quick Draw is created from New Competition, then New Quick Draw. The interface is built for public draws on a live stream or social post, hides entrant contact details on screen, emails the organizer a winners summary, and the draw is removed after 30 days, after which the winner list cannot be retrieved. Keep the summary email with the audit note.
- **Random Name Picker** (page updated 4 May 2025): paste names or upload a text file, one per line. A weighted draw appends the entry worth after a comma ("Avery Higgins, 5"). The page lists name limits by plan (1k Free, 4k Hobby, 10k Pro, 50k Business, 100k Premium as of that date) and no limit on the number of winners. Re-check the page before quoting the limits.

When the user runs the draw in Gleam, the audit note in `draw-procedure.md` still applies: record the date, the number drawn, and the announcement. When the user prefers a seed they can publish, `scripts/draw.py` on the exported entrant list gives that.
