# Drawing Winners in Gleam

Load this only when the user says they use Gleam or asks about it. Checked against the official documentation on 9 September 2026 (the post-campaign pages carry "Updated on July 27, 2026"). Re-verify before quoting plan limits, and state nothing beyond the linked pages. The same text lives in gleam-campaign-setup, keep the three copies identical.

- **The Prize tab sets the Winner count.** Prizes and the number of Winners for each are entered on the [Prize Tab](https://gleam.io/docs/competitions/setup/prizes), and total Winners is the sum across the Prize entries. The page says the number of Prizes and Winners depends on the plan without listing figures, so read it for the user's plan.
- **Random draws.** From the Winners tab, choose how many Winners to draw and optionally restrict entries by date ([Drawing Random Winners](https://gleam.io/docs/competitions/post-campaign/random-winners)). With several Prizes, drawing All Prizes assigns the first Winner drawn to the first Prize listed and so on, or draw one Prize at a time. The docs say random draws use Random.org.
- **Allow Repeat Winners** lets more than one entry from the same Entrant win ([Allow Repeat Winners](https://gleam.io/docs/competitions/post-campaign/repeat-winners)). Leave it off for one Prize per person.
- **Daily or weekly Winners.** Winners can be drawn at any time during the campaign from the Winners tab ([Daily / Weekly Winners](https://gleam.io/docs/competitions/post-campaign/daily-weekly-winners)). Date-range restriction on a draw is described as a Business-plan-and-above control, on that Daily / Weekly Winners page and not on the Drawing Random Winners page. Cite the page the limit is actually printed on, since a reader checking a plan limit clicks the link. Archiving entries after each draw starts the next pool fresh while keeping the data on the Actions tab.
- **Manual Winners** for judged and skill-based competitions, which the docs say Gleam audits ([Selecting Manual Winners](https://gleam.io/docs/competitions/post-campaign/manual-winners)).
- **Contacting Winners.** The docs state Gleam does not contact Winners automatically. The organizer announces and contacts them. Draws must follow Gleam's Terms of Service.
- **Quick Draws** are standalone tools for lists that did not come from a Gleam campaign ([Overview](https://gleam.io/docs/competitions/quick-draws/overview), page updated 8 September 2025). A Quick Draw is created from New Competition, then New Quick Draw. The interface is built for public draws on a live stream or a social post, hides Entrant contact details on screen, and emails the organizer a Winners summary. The draw is removed after 30 days, after which the Winner list cannot be retrieved, so keep that summary email with the audit note.
- **Random Name Picker** ([page](https://gleam.io/docs/competitions/quick-draws/random-name-picker), updated 4 May 2025): paste names or upload a text file, one per line. A weighted draw appends the entry worth after a comma ("Avery Higgins, 5"). The page lists a name limit per plan and no limit on the number of Winners. The limits are not repeated here, because a number copied out of someone else's page goes stale where it sits and gets quoted anyway. Send the reader to the page for the figure that applies to their plan.
- **The other Quick Draws**: [Instagram Comment Picker](https://gleam.io/docs/competitions/quick-draws/instagram-comment-picker), [Competitions Live Draw](https://gleam.io/docs/competitions/quick-draws/competitions-live-draw), [Multiple Campaign Draw](https://gleam.io/docs/competitions/quick-draws/multiple-campaign-draw).

Do not quote plan prices from memory, and do not name features beyond these pages.

When the user runs the draw in Gleam, the audit note in `draw-procedure.md` still applies: record the date, the number drawn, and the announcement. When the user prefers a seed they can publish, `scripts/draw.py` on the dataseted Entrant list gives that.
