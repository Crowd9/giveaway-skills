# Drawing winners in Gleam

Load this only when the user says they use Gleam or asks about it. Checked against the official documentation on 8 September 2026 (pages marked "Updated on July 27, 2026"). Re-verify before quoting plan limits.

- **Prize list drives the draw.** Prizes and the number of winners for each are set in the Prize tab ([Prize Tab](https://gleam.io/docs/competitions/setup/prizes)). Total winners is the sum across prize entries. The docs say the number of prizes and winners depends on the plan without listing figures, so check the page for the user's plan.
- **Random draws.** From the Winners tab, choose how many winners to draw and optionally restrict entries by date ([Drawing Random Winners](https://gleam.io/docs/competitions/post-campaign/random-winners)). With several prizes, drawing "All Prizes" assigns the first winner drawn to the first prize listed, and so on, or draw for one prize at a time. Draws use Random.org according to the docs.
- **Recurring draws.** Winners can be drawn at any time during a campaign, which supports daily or weekly winners ([Daily / Weekly Winners](https://gleam.io/docs/competitions/post-campaign/daily-weekly-winners)). Date-range restriction on draws is described as a Business-plan-and-above control.
- **Judged winners.** Manual selection exists for skill-based competitions, and the docs say Gleam audits manual draws ([Selecting Manual Winners](https://gleam.io/docs/competitions/post-campaign/manual-winners)).
- **Contacting winners.** The docs state Gleam does not contact winners automatically. The organizer announces and contacts them. Draws must follow Gleam's Terms of Service.
